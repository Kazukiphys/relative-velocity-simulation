# 相対速度ラボ

高校物理基礎の相対速度を，電車と3D車の視点で確認するシミュレーターです。

## 開発

```sh
npm ci
npm run dev
```

## XREAへアップロード

1. ローカルで `npm ci` を実行します。
2. `npm run build` を実行します。
3. `dist` フォルダーの中身を，XREAの公開ディレクトリへアップロードします。公開ディレクトリ直下で公開する場合は，`dist`フォルダーそのものではなく，中にある`index.html`と`assets`フォルダーなどをアップロードしてください。

ビルド済みファイルは相対パスでアセットを参照するため，公開ディレクトリ直下でもサブディレクトリでも動作します。ワークスペース直下の開発用`index.html`ではなく，必ず`dist/index.html`を公開してください。

## GitHub Pages

`main`へのpushでGitHub Actionsがビルドとデプロイを行います。
